# Fundamentos de Linguagem C

## Sobre o projeto

Este projeto contém exercícios acadêmicos desenvolvidos durante meus estudos de lógica de programação e fundamentos da linguagem C, como parte da minha formação em Engenharia de Software.

## Exercício: Músicas do Justin Bieber

O exercício utiliza um vetor de 10 posições para armazenar músicas do artista Justin Bieber e seus respectivos números fictícios de reproduções.

O objetivo é praticar a manipulação de vetores, a organização de dados e a ordenação de valores por meio de algoritmos desenvolvidos em linguagem C.

**Observação:** os números de reproduções utilizados são fictícios e têm finalidade exclusivamente didática.

## Tecnologias utilizadas

- Linguagem C
- Vetores
- Algoritmos de ordenação
- GitHub para versionamento e compartilhamento do código

## Objetivo

Desenvolver o raciocínio lógico, praticar conceitos fundamentais da programação e registrar minha evolução como estudante de Engenharia de Software.
